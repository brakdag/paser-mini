El contexto es espacio para pensar.
Paser Mini busca aprovecharlo al máximo.

Un agente que razona, usa herramientas y continúa la tarea. Lee archivos, edita código y ejecuta comandos desde una interfaz de texto. Mini por filosofía: dar al modelo el contexto que necesita para trabajar.

Archivos, comandos, herramientas MCP y pipelines de Unix. Una interfaz de texto para trabajar sobre tu proyecto.

Vos elegís el modelo.

Usá tu propia API key con Gemini, OpenRouter, Groq y otros proveedores, o configurá un endpoint compatible.

Del repo a la terminal.

Debian / Linux · Node.js 24 o 26 · Git

›_ instalación
git clone https://github.com/brakdag/paser-mini.git
cd paser-mini
npm ci --ignore-scripts
export GEMINI_API_KEY="tu-api-key"
npm start

Gemini es el proveedor inicial. Para usar otro, configurá su API key y seleccioná el proveedor con /connect. El consumo depende del modelo y del servicio que elijas.

Leer la documentación ↗ Pipelines y endpoints ↗

¿Venís de OpenRouter?

Paser Mini es un cliente independiente. Usá OPENROUTER_API_KEY y elegí OpenRouter con /connect. La disponibilidad y las condiciones de cada modelo las define el proveedor.
